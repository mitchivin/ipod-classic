# iPod Classic

A click-wheel music player for the browser and a desktop widget for Windows.

**[Download for Windows](https://github.com/mitchivin/ipod-classic/releases/latest) · [Open live demo](https://mitchivin.github.io/ipod-classic/) · [Explore in DoodleDev](https://doodledev.app/builds/#ipod-classic)**

Current release: **0.0.29**. Free to use. Works on desktop and phone.

![iPod Classic Now Playing](assets/ipod-classic-playing-device-1920x1080.webp)

## Features

- **Click wheel.** Scroll, select and control playback with the circular wheel.
- **Music library.** Browse artists, albums, songs and playlists, or pick Shuffle Songs from the main menu.
- **Now Playing.** Album artwork, track details and playback progress.
- **Photos.** Browse album art in a grid or play it as a slideshow.
- **Settings.** Shuffle, Repeat, Sound Check and slideshow timing.
- **Import your music.** Add songs from your own computer or phone.
- **Media keys.** Play, pause and skip from your keyboard's media keys or your phone's lock screen.
- **Right-click menu.** Right-click or long-press the device for Mute, About and GitHub.
- **Desktop widget.** On Windows it's just the device on your desktop: a see-through window you drag anywhere, with a tray icon. Always on Top, Minimize and Close are in the right-click menu.

![iPod Classic menu](assets/ipod-classic-menu-device-1920x1080.webp)

## Keyboard

| Key | Action |
| --- | --- |
| ↑ ↓ | Turn the wheel |
| Enter | Centre button |
| Esc or Backspace | Menu |
| Space | Play or pause |

## Get started

### Windows desktop widget

1. Download the **Setup installer** from [Releases](https://github.com/mitchivin/ipod-classic/releases/latest) and run it.
2. The installer isn't signed, so Windows may show "Windows protected your PC". Click **More info**, then **Run anyway**.
3. The widget starts with an empty library. Choose **Import Music** to add your songs.

### Browser

1. Open the [iPod Classic live demo](https://mitchivin.github.io/ipod-classic/).
2. Browse the demo library and choose a track.
3. Use the click wheel to control playback.
